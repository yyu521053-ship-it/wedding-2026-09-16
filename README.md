# 于清旭与成冰冰互动婚礼请帖

纯静态 H5 婚礼请帖，适合发布到 GitHub Pages。

## 本地预览

请在本目录启动任意静态文件服务器，不要直接双击 `index.html`：

```powershell
python -m http.server 4173
```

然后访问 `http://127.0.0.1:4173/`。

## GitHub Pages

1. 创建公开仓库 `wedding-2026-09-16`。
2. 将本目录中的文件提交到默认分支根目录。
3. 在仓库 Settings → Pages 中选择从默认分支根目录发布。
4. 等待 Pages 显示 HTTPS 网址后进行公网复查。

## 隐私说明

本仓库包含处理后的新人像素图片、婚礼时间、公开地址和高德地图链接，不包含原始高分辨率照片、登录凭据或宾客数据。
